# Get all interaction labels from WBFormula

Get all interaction labels from WBFormula

## Usage

``` r
get_interactions.WBFormula(x, type = c("all", "within", "cross", "between"))
```

## Arguments

- x:

  A WBFormula object

- type:

  One of "all", "within", "cross", or "between"

## Value

Character vector of interaction labels
