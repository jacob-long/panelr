# Create WBFormula from parser output (for migration)

Create WBFormula from parser output (for migration)

## Usage

``` r
WBFormula_from_parser(pf, formula, dv)
```

## Arguments

- pf:

  List output from wb_formula_parser()

- formula:

  The original Formula object

- dv:

  The dependent variable name

## Value

A WBFormula object
